# date-extensions.js

[Date](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Global_Objects/Date)オブジェクトに追加の便利メソッドを追加するモジュールです。

追加されるメソッドについては[ソースコード](date-extensions.js)を確認してください。

## CDNからの利用

```html
<script type="module" src="https://js.plasticheart.info/date-extensions/latest/date-extensions.min.js"></script>
```

- 非同期で読み込まれるので、必要に応じて `DateExtensionsLoaded` イベントを待機してください
